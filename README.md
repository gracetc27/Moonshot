# Moonshot 
Project 8 in my 100 days of SwiftUI- Hacking with Swift journey. This app presents space missions in a grid or list view. You can click on a specific mission to view more information about it.
This detail view also has a scrolling list of Astronauts in which you can click on and find more information about them too.
# Features
- More experience with codable.
- ScrollViews and creating scrolling grids.
- Image formatting.
- Using NavigationLink.
